## 一、产品定位

「养猪小计划」是一个**粤语生活节点记录器**：用「XX未」问句式按钮，一键记录自己每天在各生活节点做了什么——训醒、食咗、饮咗、屙咗、运动、来M、穿搭、DDL……

核心理念：**把自己当猪养，记录生活 = 喂自己**。首页顶部「今日喂咗自己 X 次」就是这个隐喻的落地。

### 三大页面

| 页面 | 职责 |
|------|------|
| 首页 | 快捷记录（分组节点 + 多状态选项面板）|
| 全记录 | 时间线（图文混排，穿搭为大图卡片）|
| 汇总 | 统计（总记录/连续天数/来M周期/DDL）|

---

## 二、节点模型（5 类）

| 类型 | 节点 | 记录字段 |
|------|------|----------|
| 状态打卡 `status` | 训醒未 / 训着未 / 屙咗未 | 选项 + 时:分 |
| 频次 `count` | 食咗未 / 饮咗未 / 八段锦 / 郁下 | 选项 + 时:分 + 备注文字 |
| 穿搭 `photo` | 几靓呀 | 上传图片 + 备注 |
| 周期 `period` | 来M未 | 开始日 / 结束日（算周期、预测）|
| 事件 `event` | DDL了 | 自定义文本 + 截止 + 订阅消息提醒 |
| 自定义 `custom` | 仲有咩 | 用户自建节点 |

节点唯一数据源在 `miniprogram/config/nodes.js`，三个页面共用。

## 三、系统架构

```
小程序客户端（原生 WXML/WXSS/JS）
        │ wx.cloud.*（免域名白名单）
微信云开发（后端，免运维）
  ├─ 云函数：login / saveEvent / savePeriod / saveDdl / ddlReminder
  ├─ 云数据库：events / periods / ddls / users
  ├─ 云存储：穿搭图片
  └─ 定时触发器：ddlReminder（每小时扫描提醒）
        │
微信开放能力：静默登录 / 订阅消息 / 分享裂变
```

## 四、数据模型

### events（日常打卡）
```
id / openid / date / nodeId / option / time / note / images[] / createdAt
```

### periods（来M 周期，跨天区间）
```
id / openid / startDate / endDate(null=进行中) / createdAt
```

### ddls（事件提醒）
```
id / openid / content / dueAt / remindAt / reminded / status / createdAt
```

### users（用户）
```
openid / coins / createdAt
```

## 五、关键实现说明

### 5.1 交互模式
- 点 chip 主体 = 展开面板（选项 + 按类型补充字段）
- 保存后 chip 显示 ✓ + 状态 + 时间

### 5.2 来M 周期计算
- 开始日/结束日分开记录，`endDate=null` 表示进行中
- 汇总页算：持续天数、平均周期（相邻开始日间隔均值）、下次预测

### 5.3 DDL 提醒（重要约束）
小程序**无法设置系统级闹钟**，只能用**订阅消息**实现：
1. 用户创建 DDL 开提醒时，`wx.requestSubscribeMessage` 授权（一次性）
2. 云函数 `ddlReminder` 定时触发器每小时扫描 `remindAt<=now 且 reminded=false`
3. 发送订阅消息 → 标记 `reminded=true`

订阅消息是「一次性」的，一次授权发一条，需后台申请模板。

## 六、项目结构（已搭建）

```
养猪小计划/
├── project.config.json        # 云开发项目配置（替换 appid + 环境 ID）
├── cloudfunctions/            # 云函数
│   ├── login/                 # 静默登录
│   ├── saveEvent/             # 保存日常记录
│   ├── savePeriod/            # 保存来M周期
│   ├── saveDdl/               # 保存 DDL 事件
│   └── ddlReminder/           # 定时提醒（含 config.json 触发器）
├── miniprogram/
│   ├── app.js / app.json / app.wxss / sitemap.json
│   ├── config/nodes.js        # 节点唯一数据源
│   ├── utils/cloud.js         # 云函数调用封装
│   └── pages/
│       ├── index/             # 首页（快捷记录）
│       ├── records/           # 全记录（时间线）
│       └── summary/           # 汇总（统计）
└── docs/架构设计文档.md
```
